## 先尝试网页内运行

先用小型 [预览能力探针](../examples/preview-probe.html) 检查脚本与交互，再使用 [网页工作流](../prompts/README.md) 上传对应 HTML 和提示词。探针通过仅表明该页面可执行探针，还需要课件验收。优先原样预览附件或只替换 `lesson-data` 数据块；用页面内输入框载入新 JSON。看到代码、文件链接或截图还不算成功：至少实际操作一次播放、拖动与重载。

若平台不能执行完整脚本，先保存 JSON 和原模板，明确记录“当前会话未确认执行预览”。可下载到普通浏览器打开并导入 JSON，作为降级路径；不把它记成平台内成功。不要为了适应沙箱删掉校验或改成模型编造的逐帧数组。

## 最小人工验收

每个平台分别做一次；国际 Qwen 与国内千问分开记录。原题与模型语义仍需人工核对。以下是自拟回归题，无教材来源声明。

| 检查 | 操作 | 期望 |
|---|---|---|
| 初次预览 | 附上运动模板，载入 v₀=0 m/s、a=2 m/s²、t=3 s | 题干与数据正确；终点 s=9 m、v=6 m/s；题意与模型项仍待审查 |
| 运动同步 | 拖至 t=1 s，播放、暂停、步进、重置 | s=1 m、v=2 m/s；位置与数值同步；暂停后时间不继续推进 |
| 方向与换算 | 换 v₀=36 km/h、a=−2 m/s²、t=8 s | 终点 s=16 m、v=−6 m/s；反向阶段不被误当为路程 |
| 电路重载 | 在电路模板载入 60 V 与 10 Ω、20 Ω 串联，再把电压改为 90 V | 电流由 2 A 变 3 A，图中标签、分压与读数一起更新；保留电流示意说明 |
| 截面 | 载入边长 2 cm 正方体与经过 (2,1,0)、(2,0,1)、(1,0,2) 的平面 | 正六边形；面积≈5.196152 cm²；旋转只改变相机 |
| 错误拦截 | 运动 a 的单位改为 s；另测把 s 的用户 claim 写成 8 m | 清楚报错；不显示成功答案，动画区清空且不可播放 |
| 题设定位 | source 填入题干不存在的片段；再删掉 source 重试 | 前者报错；后者允许计算但保留未定位/待核对提示 |
| 文字解法 | 加入一段 solutionText，保留合法输入 | 原文可查看，文字推理仍待审查；不自动宣布整篇正确 |
| 同题型复用 | 只让模型返回 JSON，粘贴输入框载入 | 不需重新生成 HTML 或逐帧数据，题干与结果均刷新 |

建议记录：日期、平台及实际地址、国际/国内版本、账号可见模式、浏览器版本、使用的模板版本/提交、各项通过/失败/未测、错误信息或截图。只有实际执行后才填写“通过”；新账号/模式切换后不能沿用旧账号结论。

## 本地验证的解释

仓库中的 `tests/lesson.test.mjs` 验证模型与输入边界；`tests/lesson-html.test.mjs` 在模拟 DOM 中检查导出启动、同步交互、重载与错误拦截。维护者应报告实际运行命令和结果，不在这里固化测试数量。

模拟 DOM 不等同于浏览器完整视觉验收，普通浏览器验收也不等同于 ChatGPT/DeepSeek/豆包/Qwen 账号验收。`animation: passed` 检查只说明使用同一求解状态，不能证明宿主已经播放成功。模板被模型改写内核后，原模板的测试证据不再自动适用。

2026-11-02补充：现有综合题报告的SVG查看器有DOM交互测试；它是可选独立图解组件，不会自动加入三个固定模板。复杂题网页提示词另走探索图解路线，不能沿用固定模板的测试结论。额外验收：每幅图可打开、缩放、拖动、复位和关闭；步骤高亮、时间动画及参数联动若实现再分别检查。DOM测试不改变上表“账号未测试”的状态。

本次尝试通过浏览器工具打开本地 `file:///` 课件时被工具安全策略拒绝；未绕过该限制。因此本轮只有离线模拟 DOM 验证，真实 Chromium、移动端视觉与平台账号测试均待进行。这是工具访问限制，不是课件或聊天平台不支持的证据。
