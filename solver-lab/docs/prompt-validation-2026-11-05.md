# 网页提示词整理与题型复核

整理开始于2026-11-04，收尾于2026-11-05。本轮修改提示词与导航，未扩展计算接口。使用入口见[提示词导航](../prompts/README.md)。

## 修改内容

- 保留通用、复杂题两个主入口；使用时选一个，可另选一份题型与一个平台补充词。新增函数/数列、几何、概率统计、力学、电路/场、光学、热学七份补充词。
- 布局修复不再写死匀减速、传送带或v-t图。长说明放图外，静态题不强加时间轴；固定模板若要改布局，保留原版、另存标注的衍生版并重新检查。
- 补全截面正多边形、边数3–8、外接圆半径、坐标与construction约束；输出目标不是任意反求接口，并联题不能塞入串联模板。
- 区分新题与“其余不变”的变式；重新计算分支并清除失效读数。原错误解法/claims和失败证据保留，订正版单独标注。
- 附件与本地路径不假定网页可读；平台附加词只适配当前实际能力。图解评审仍默认关闭，基本正确性与防遮挡检查照常。
