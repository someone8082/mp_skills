# 网页图解的布局与标签

适用于新生成或修复的独立HTML/SVG讲解。文字堆叠、图文遮挡和窄屏裁切属于基本可读性问题，正常交付就应处理，不需要先开启额外的图解评审。

## 先分信息，再安排坐标

- 标题、阶段长句、公式解释、单位和完整数值放在正常HTML文档流中，允许换行；不要写成SVG内的长text，也不要用绝对定位压在图上。
- 图内保留短点名、量符号、必要刻度。长数值放固定读数卡，符号含义放图例；不要让完整说明随物块或动点挤到端点。
- 同一物块附近挤着速度、摩擦、重力分量时，可把运动位置图和局部受力图分开。受力图明确研究对象，箭头含义、原点、方向和比例保持物理一致；不能为错开标签而把力画到错误位置。
- 运动图、受力图和函数图分别有图框、标题与说明，采用Grid/Flex正常排版。独立缩放只作用于对应的绘图区，不同时缩放标题、图例、读数和下一幅图。

## 响应式和绘图区

- 容器用`minmax(0,1fr)`或`min-width:0`允许收缩；SVG用viewBox和容器宽度，避免固定640px内容塞进更窄的overflow:hidden容器。
- 多列在窄屏改为单列；控件允许换行，长阶段说明的高度随内容增长。不要靠整体缩小字体、把内容裁掉或让整页横向滚动解决堆叠。
- 小屏内的刻度图若无法同时保证可读与完整，可在该图自己的容器中横向滚动，明确提示；页面本身仍保持正常宽度。
- 绘图区为端点、箭头尖端、动态标签和公式外廓预留空间；只让几何中心在viewBox内不够。默认或复位视图应显示完整研究区间，不能要求先拖动才找到端点。

一个可调整的结构：

```html
<header>标题与题设摘要</header>
<section>播放、时间轴和可换行的阶段说明</section>
<dl>固定数值读数</dl>
<div class="diagrams">
  <section><h2>运动位置</h2><div class="viewport"><svg>短点名和方向</svg></div></section>
  <section><h2>局部受力</h2><svg>力的符号</svg><p>力值与关系说明</p></section>
</div>
<section><h2>函数图</h2><div class="chart-scroll"><svg>刻度与图线</svg></div></section>
```

这是一种拥挤物理图的排版选择；简单图不必硬套所有分区，几何题也可保留一幅足够清楚的主图。

## 动态标注

默认优先固定读数区；确需移动标签时，依据文字实际外廓、视口边界、其他标签和关键对象选锚点，可用短引线关联。仅对箭头末端加固定的`x+6,y-6`不足以覆盖初态、阶段切换和端点。

在关键状态检查：初始、各阶段边界前后、转向/零速、物体靠近两端和终点。无标签碰撞不能只由初始帧断言。图中文字、图与说明之间都不能堆叠；箭头与物体允许按语义相接，但不能遮住点名或关键量。

函数图的图线、刻度、事件线与当前点共用坐标映射。图标题也须符合实际运动，不能把恒加速度的减速阶段写成“加速减速”。终点若停止研究，说明显示离开前还是离开后的状态；不能清零摩擦却保留原先零加速度而隐瞒状态口径变化。

## 实际检查

有浏览器工具时，在正常桌面宽度和约360–390px窄视口查看完整页面；点事件跳转、拖时间轴、暂停、复位，查看每个阶段的实际成图。文字外廓/越界检测可辅助定位问题，不能替代对箭头、点名、公式和图文关系的截图检查。

没有运行或看到成图时明确“未做浏览器视觉核验”，仍按上述结构减少碰撞风险，不声称已保证无重叠。保留完整HTML供用户运行。现有模板或其他案例通过的测试不能替新生成页面作视觉保证。
