# 豆包平台补充提示词

与 [通用提示词](web-common.md)、对应 HTML 附件、题目一起发送：

```text
请优先使用当前豆包聊天页面实际可用的网页/代码预览入口。若可执行附件模板，请原样打开，或只替换 lesson-data JSON 后返回完整 HTML。若当前不能可靠编辑附件，就只给 LessonSpec JSON，让我粘贴到原模板预览的输入框。

不要把火山引擎 Ark/方舟的 Canvas 或开发者示例当成当前豆包消费端账号的运行证据。请根据实际播放、拖动和导入测试说明结果。若当前只显示源码或静态图，写“当前会话尚未确认完整脚本执行预览”，保留 JSON 交付。
```

豆包消费端聊天的完整 JavaScript 预览目前未验证；“未验证”不等于“不支持”。详见 [兼容性记录](../docs/browser-compatibility.md)。
