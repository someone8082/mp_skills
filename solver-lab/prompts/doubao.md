# 豆包平台补充提示词

先提供一个主入口：[通用提示词](web-common.md)或[复杂题图解提示词](web-advanced.md)，可再附一份题型补充词；下方只复制text代码块。平台补充只适配展示能力，不改题型和数学物理规则。

```text
请优先使用当前豆包聊天页面实际可用的网页/代码预览入口。固定模板路线只替换lesson-data；不能可靠编辑附件则保留LessonSpec JSON供原模板导入。复杂题按已提供的图解要求保留完整条件，生成独立SVG图解HTML，提供缩放、拖动和复位，不能冒充固定模板已核验。

先确认附件实际可读，不依赖未提供的本地或仓库相对文件。长说明、公式和完整读数放图外正常排版，拥挤关系分图、窄屏换行，不把所有内容放进统一缩放的固定画布。另行修模板布局时保留原版并另存衍生版重新检查；普通换题不改模板，新题也不继承旧数值和claims。

不要把火山引擎Ark/方舟的Canvas或开发者示例当成当前豆包账号的运行证据。按实际路线测试播放/导入或大图缩放/拖动/复位；有时间或参数演示再测暂停、拖动、事件跳转及图与读数同步。只显示源码或静态图时写“当前会话尚未确认完整脚本执行预览”；固定模板保留JSON，复杂题保留题解和完整HTML。
```

豆包消费端聊天的完整 JavaScript 预览目前未验证；“未验证”不等于“不支持”。详见 [兼容性记录](../docs/browser-compatibility.md)。
