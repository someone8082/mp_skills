# 可选图解评审附加提示词（仅想开启时复制正文）

本题图解评审：开启。请在现有解题流程中增加以下评审；不替代数理正确性检查，不改固定模板内核，也不新增LessonSpec字段。

1. **是否需要图**：指出图能帮助理解的具体关系，例如空间位置、辅助构造、受力方向、跨界事件或参数变化。仅单步代入、重复数字时可建议不画。给出“必需/有帮助/无需”及一句理由；用户明确要求画图时仍按请求提供，不因建议无需就取消。
2. **怎样画**：围绕该关系选择最少的静态图、构造步进、物理时间动画或几何参数演示；保留题中点名、坐标/单位，说明关键辅助线或向量为什么出现。不要为了美观更改条件、比例关系或方向；示意不按比例、局部放大及归一化应明示。
3. **是否直观**：看实际成图，检查研究对象、已知与辅助关系能否辨认，标签/根式有无重叠和裁切，箭头/图例是否清楚，关键步骤或事件是否容易定位。动画检查暂停后向量、读数与说明同步；放大图能否回到全图。没有看到实际图时写“未视觉核验”，不能用代码、DOM测试或口头自评代替。

复用已有题设、模型和文件，在当前流程中只做一次绘图选择和一次成图检查，默认用三行概述“是否画、画法、直观性”。必要时最多增加一轮针对性修正；未解决的明确说明，不反复整页重生成、不生成多套候选图或长评分表，不主动另开模型/子代理、付费服务或联网评审。原有数理错误仍须纠正，不能以次数上限为由称成功。不开启时不额外评审，也不关闭正常绘图和基本正确性检查。
