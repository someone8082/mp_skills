# 手机端：复制代码后运行图解

使用[数理图解 · 手机预览器](https://solver-lab-mobile-20261106-8082.wwk58317.chatgpt.site)。网站已设置为公开访问，无需模型API密钥；手机不必新建HTML文件。系统浏览器通常比聊天应用内置浏览器更适合运行交互页面。

1. 在聊天网页中提供原题、一个主提示词和确实需要的题型补充词；追加下方手机交付要求。
2. 复制模型返回的完整HTML代码，或受支持的LessonSpec v1 JSON。不要连同代码块外的题解一起复制；一组完整的代码围栏可保留。
3. 打开预览器，在输入框长按粘贴，点击“运行图解”。剪贴板按钮不可用时，仍可手动长按粘贴。
4. 顶部“编辑”返回输入，“停止”卸载当前图解；修改后重新运行。最近三条记录与草稿仅保存在当前浏览器，清除浏览器数据会丢失。

## 追加给模型的提示词

已有主入口时只追加此段，不重复发送其他所有平台提示词：

```text
我全程使用手机，会把你返回的代码复制到独立预览器运行，不需要在手机上新建文件。请保留题解，并将交互图解放在一个完整代码块内，便于整段复制。

若本题完整适用已提供的LessonSpec v1格式，只返回一个完整合法JSON代码块作为图解数据，不输出ProblemSpec、零散补丁或缺字段JSON；预览器支持motion（一维恒加速度）、circuit（理想串联）和section（格式支持的标准实体截面），会调用固定内核检查。没有已提供的格式或题目超范围时，交付完整单文件HTML，不猜字段或把复杂题硬套模板。

HTML的CSS、JavaScript、SVG均内联，不引用CDN、外部字体、远程图片、联网接口或其他文件；根号、分数与上下标使用原生HTML/SVG排版，不依赖外部公式库。预览器在隔离iframe中运行，不能访问父页面、打开新窗口或下载文件；需要的控件与计算应在本页内完成。

按约360–390px的窄屏设计：图框单列、控件便于触摸、长说明在图外换行，图内只留短标记。沿用原题的推导、适用条件与事件边界，不添加数值条件来方便动画。实际未运行的计算、交互和视觉检查分别注明未测；输出完整代码不等于已经在我的手机上运行成功。
```

## 支持与限制

- HTML预览解决打开和运行，不能自动修复原页面的公式错误、标签重叠或不完整代码。修布局仍使用[布局修复提示词](web-layout-repair.md)。
- JSON输入由固定内核检查，其支持边界与[通用提示词](web-common.md)一致；编译通过仍需核对题意，不代表任意证明通过。
- 课件代码不主动上传，运行与最近记录在当前浏览器；首次打开网站、载入模板和示例需要网络，第一版不承诺离线使用。
- 网站公开权限与手机网络可达性是两项检查。遇到403、白屏或无法连接时，先保留代码；不要声称学生端已验证成功，也不要要求关闭浏览器安全保护。
- 已有本地浏览器窄视口验证；安卓/iPhone实机、聊天内置浏览器和各地区网络仍需实际验证。
