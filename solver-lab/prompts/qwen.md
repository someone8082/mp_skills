# Qwen / 千问平台补充提示词

先提供一个主入口：[通用提示词](web-common.md)或[复杂题图解提示词](web-advanced.md)，可再附一份题型补充词；下方只复制text代码块。平台补充只适配展示能力，不改题型和数学物理规则。

```text
请区分国际Qwen Chat与国内千问，以当前页面实际出现的Artifacts/代码/网页预览入口为准。固定模板优先原样预览附件或只替换lesson-data，后续同题型只给JSON。复杂题按已提供的图解要求独立推导并生成SVG图解HTML，提供缩放、拖动、复位及步骤对应，不伪造固定模板JSON。可可靠编辑现有文件时后续只更新数据或对应片段。

先确认附件实际可读，不假装读取仓库相对路径。长说明和完整读数放SVG外，多图独立分区、窄屏单列，布局检查不依赖额外评审开关。单独修固定模板布局时保留原版、另存衍生版并重新检查，不沿用仅导入数据时的认证口径。新题重新提取条件，缺参或无解时清理旧成功读数。

生成独立 HTML 时，让几何图形的点、线、交点和角标共用同一坐标变换。线段连接真实端点，延长时从真实端点沿方向向量延伸。角标的屏幕尺寸先换算到绘图单位。若涉及动弦或垂直方向，用已知构型核对弦通过标注点、端点在曲线上、两方向垂直。水平线斜率为 0，竖直线斜率未定义，仅在两个斜率均有定义时显示乘积。

若要求数构型，为每个原对象选唯一代表。换元后逐根还原原对象并回代原式。遇到无序直线对，把两条直线都列出，分别检查交换和镜像所得集合是否相同，再去重计数。验收时分别取临界点本身和两侧可达的测试值。检验极值两侧时把三个参数分别代入计算。微小非零差值用科学计数法或严格不等号，接近临界点时保留原有分支。

分别检查 320px 和 390px 宽度下 SVG 点名、刻度的实际渲染字号，关键标注以至少 12px 为目标。按容器重排或减少标注，把长图注和读数移到图外。滑块在 input 后保留焦点，验收连续按方向键、拖动、暂停与复位后图形和读数是否同步。纯函数自检和真实浏览器交互分别列出实测结果。

不要把国际Qwen Chat的Artifacts文档当成国内千问账号的功能保证，也不要从模型API推断前端执行JavaScript。未执行时如实说明；固定模板保留JSON，复杂题保留题解和完整文件。按实际提供的播放/导入或大图缩放/拖动分别验收；有时间或参数演示再测暂停、拖动、事件跳转及图与读数同步，不把静态图说成动画，也不把生成文件说成预览已通过。
```

Qwen 官方历史公告提及国际 Qwen Chat 的 Artifacts；本项目未做国际 Qwen Chat 或国内千问的登录账号实测。详见 [兼容性依据](../docs/browser-compatibility.md)。
