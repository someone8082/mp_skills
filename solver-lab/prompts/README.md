# 在聊天网页里使用

目标是在你当前的 ChatGPT、DeepSeek、豆包或 Qwen/千问页面里直接看课件。固定模板路线由模型整理题设、原HTML负责计算；复杂题路线先推导和核对本题模型，再生成独立图解。无需配置API Key、CDN或部署；交互预览仍须聊天网页允许执行内嵌JavaScript。

当前未做任何平台的登录账号实测，不能保证某个账号会出现预览按钮。[兼容性说明与验收表](../docs/browser-compatibility.md) 区分文档证据和实际测试结果。

## 按题目选入口

- 一维恒加速度、理想串联电路、标准截面：走下面的固定模板路线，计算由原内核完成。
- 综合力学、解析几何范围/证明、三维约束，或没有适用模板：直接复制[复杂题图解提示词](web-advanced.md)，附题目和可选解法，再加对应平台补充即可。可独立使用，不必先上传三个不适用的模板。新HTML是独立探索图解，核验范围据实际执行说明。
- 想统一使用一个入口：复制[通用提示词](web-common.md)，它会先判断固定模板还是复杂题图解；不要为超范围题伪造LessonSpec。

两条路线都以图解帮助理解；图像缩放、构造步进、时间播放和改参数分别验收。新复杂题图解提示词要求SVG和看图交互；旧固定模板不因此自动获得缩放功能。参考答案可用于对照，不将已读解析的试用称为盲测。

本轮补充：离线数学字形避免字体依赖；粒子跨场等过程可使用模型驱动的时间演示，几何动点可按参数步进。它们是独立图解的制作要求，不表示固定CLI新增了电磁场任务，也不表示所有题都应动画化。

## 第一次使用

1. 可先附上小型 [预览能力探针](../examples/preview-probe.html)，确认当前页面是否能响应脚本交互；探针通过仍需验收正式课件。再选对应模板：[运动](../examples/lesson-motion.html)、[串联电路](../examples/lesson-circuit.html)、[立体截面](../examples/lesson-section.html)。保留原文件，附到聊天中。若平台不能读取附件，将完整 HTML 粘贴为代码附件或代码文本；不要省略内核。
2. 粘贴 [通用提示词](web-common.md) 的完整正文，再附上一个平台提示词：[ChatGPT](chatgpt.md)、[DeepSeek](deepseek.md)、[豆包](doubao.md)、[Qwen/千问](qwen.md)。填入原题和可选的用户解法。截图可一并上传；检查模型是否抄对符号、单位与图上关系，模糊处不能猜。
3. 要求平台创建可交互 HTML 预览。如果它能编辑附件，只替换 `lesson-data` 数据块并返回完整 `.html`；如果不能可靠保持文件其余内容，要求只返回 JSON，并让平台先原样预览附件模板。
4. 在 HTML 预览内，将新 JSON 粘贴到输入框，点击“载入并核验”。先确认显示的是你的题干，而非模板示例。若当前界面无执行预览，报告“当前会话尚未确认可执行”，不要把代码块或静态截图当成运行结果。
5. 核对待审查项，操作播放/暂停、拖动时间轴和步进；用 [最小验收](../docs/browser-compatibility.md#最小人工验收) 检查数字和错误拦截。

“返回完整 HTML”便于首次建立预览，但会重复输出模板。能直接原样预览附件时，首次也可只输出 JSON；不要为减少 token 要求模型删掉验证代码。

## 后续换题：只生成 JSON

在同一个预览中使用同题型的课件，继续发：

```text
继续使用刚才的同题型模板。按照已有 LessonSpec v1 只返回一个合法 JSON 对象，不加 Markdown，不输出 HTML，不生成逐帧数组。保留完整题干、明确单位和用户解法；source 逐字引用题干。条件不足或超出题型时先说明缺口，不造数据。
新题：……
我的解法（可选）：……
```

复制 JSON 到导入框重新载入即可，播放不消耗模型调用。换到另一题型时更换对应 HTML 模板。每次仍需确认模型提取与假设；低 token 不代表已自动保证正确性。

## 已有独立图解：只补动态展示

不必重新粘贴全部提示词与教材。同一会话已保留解答和图解时，可发送：

```text
沿用刚才的题设与已核对推导，为确实有助理解的过程补演示。先判断采用物理时间还是几何参数；静态关系继续保留。动态图、向量、读数和说明共用一个状态函数，支持暂停、拖动、复位与关键事件跳转。符号量归一化须说明尺度；核对跨界、零速和终点，不能用速度为零推出受力为零。根号、上下标离线清晰，保留静态大图。可可靠编辑时只修改相关片段，否则给完整文件。交互在本地计算；未运行的检查和平台预览如实标未测。
```

当前会话没有保留模型时，补发有关题干、模型与文件即可；播放和缩放不需要再次问模型。细节见[复杂题提示词](web-advanced.md)，无需每轮重复四个平台补充或整本教材。

## 只有提示词，没有模板

题型适用时优先使用上述单文件模板。没有模板或整题超出固定范围时，使用[复杂题图解提示词](web-advanced.md)。若只需简短补充，可在通用提示词后加：

```text
本次没有适用的solver-lab模板。请先解题，再生成无需网络/CDN、内嵌SVG的单文件HTML图解，点名、单位、辅助关系与推导对应，提供可执行的缩放、拖动和复位。物理过程可按时间播放，几何可构造步进或参数演示；图与数值使用同一模型，公式离线清晰。标注“AI独立图解，未使用solver-lab受测模板”；没有执行时写“未运行验证”，不能引用仓库测试为本文件背书。不补造条件，只实现本题所需内容。
```

此路径生成的代码需要单独审查与测试，不能声称复用了本仓库内核。平台没有执行预览时，A路线可下载原模板到普通浏览器导入JSON；B路线下载新生成的完整图解HTML到普通浏览器打开，不假设它含模板的JSON导入框。两者都是明确的降级路径，不是网页内预览已成功。
