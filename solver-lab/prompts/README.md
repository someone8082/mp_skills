# 网页提示词：选择、补充与续接

目标是在当前聊天网页解题并查看图解。固定模板负责受支持的计算；独立图解按本题建模和验证。网页不会自动加载本仓库、安装目录或知识卡，链接与附件也不保证可读。

## 最少使用组合

**一个主入口 + 可选的一份题型补充词 + 可选的一个平台补充词 + 本题材料。** 不要把两个主入口和所有题型一次粘贴。

| 情况 | 主入口 | 实际需要附的内容 |
|---|---|---|
| 不确定题型，或使用一维恒加速度/理想串联/标准截面模板 | [web-common.md](web-common.md)，复制完整正文 | 本题原文；走模板时附对应完整HTML |
| 已知是综合题、证明/范围题、一般电路或没有适用模板 | [web-advanced.md](web-advanced.md)，复制完整正文 | 本题原文与图；无需先附不适用的三个模板 |
| 已有页面，只修堆叠/裁切 | [web-layout-repair.md](web-layout-repair.md)，只复制text代码块 | 当前完整HTML和问题截图；原会话已有可读文件可复用 |
| 只想额外做教学图解评审 | [web-visual-review.md](web-visual-review.md)，另行复制正文 | 用户明确开启时才添加，普通可读性检查仍默认执行 |

主入口能独立说明基本流程；题型补充用于较复杂边界，按需选一份：

| 题型 | 补充词 | 重点 |
|---|---|---|
| 函数、导数、数列、不等式 | [数学代数类](subjects/math-functions.md) | 定义域、分段跨界、首项、参数退化、可达端点 |
| 平面/解析/立体几何 | [数学几何类](subjects/math-geometry.md) | 竖直线、分支、三维投影、完整截面与作图 |
| 计数、概率、统计 | [概率统计类](subjects/math-probability.md) | 样本空间、独立条件、分布支持与统计口径 |
| 追及、传送带、板块、圆周、碰撞等 | [力学](subjects/physics-mechanics.md) | 事件先后、相对运动、约束与守恒 |
| 电路、电场、磁场、感应 | [电路与场](subjects/physics-circuits-fields.md) | 拓扑、理想条件、方向与跨界 |
| 折射、全反射、透镜等 | [光学](subjects/physics-optics.md) | 法线角、介质顺序、虚实与临界 |
| 气体过程、热平衡等 | [热学](subjects/physics-thermal.md) | 系统、绝对温度、过程与功的符号 |

每份补充词只复制其text代码块。跨学科题可取确实相关的两份，不将规则当作额外题设。平台补充同样只选当前平台的text代码块：[ChatGPT](chatgpt.md)、[DeepSeek](deepseek.md)、[豆包](doubao.md)、[Qwen/千问](qwen.md)。平台词仅适配展示能力，不负责重新定义题型。

若要使用方法卡，附上本题有关的卡片正文或可读文件；没有提供就不能声称读过，更不能声称在网页运行了本地study.mjs。只给一个GitHub目录链接不是自动安装skill。

## 固定模板首次使用

1. 可先附[预览探针](../examples/preview-probe.html)检查当前会话能否执行脚本；探针通过不代表正式课件全部通过。
2. 附对应完整HTML：[运动](../examples/lesson-motion.html)、[串联电路](../examples/lesson-circuit.html)、[截面](../examples/lesson-section.html)，以及web-common正文和原题。截面需要带点名逐步作图时，可额外附[完整construction示例](../lesson/examples/section-construction.json)，明确它只用于格式参考。
3. 优先原样预览模板并导入JSON；若模型能可靠保留其余内容，也可只替换lesson-data。不能可靠编辑时只给JSON，不删内核或校验。
4. 确认页面显示的是本题而非模板示例，再测试载入、错误拦截及实际具备的播放/步骤控件。字段、支持边界和坐标映射均在web-common中说明；题意仍需核对。

模板要求的givens是输入，不是任意反求接口。缺v0/a/t的运动逆问题、求总路程、并联电路、任意直棱柱等可走独立图解，不把上游推导量冒充原始已知。

## 同题型换题与参数变式

原模板中换一道完整新题，可在原会话复制：

```text
继续使用当前同题型原模板，按已提供LessonSpec v1只返回一个合法JSON对象，不加Markdown，不输出HTML或逐帧数组。
这是新题：请重新提取完整题设、单位、目标和我实际提供的解法，不继承上一题数值、claims或模型条件；source只引用这次题干中的原文。缺关键条件或不完整适用模板时说明原因并改走独立推导，不造JSON。
新题：……
我的解法（没有则省略）：……
```

已有独立图解，只改变明确参数时复制：

```text
沿用当前题设与图解，变更如下：……；其余条件不变。
重新求解并检查分支、定义域/有效区间、关键事件和目标；同步更新图线、图例、读数、步骤和检查状态，不显示上一参数的旧答案。无解、退化或缺参数时清理旧成功读数并暂停相关动画，说明原因。能可靠编辑就更新有关部分，否则返回完整文件；改参数不是仅改播放倍率。
```

新题若改变电路拓扑、几何模型或运动阶段，就重新选路线；不是同topic名称就必然适合旧模型。

## 已有图解：补动态或修布局

布局问题用web-layout-repair；它不预置加速、减速、摩擦方向或图的类型。若对象是固定模板且必须改CSS/绘图，保留原版另存有标注的布局衍生版，重新核验，而不是既要求不可改又要求改布局。

只补真正有用的动态演示，可在已保留题设和推导的会话复制：

```text
沿用本题已核对的条件和推导。先判断适合构造步骤、几何参数还是物理时间，静态关系不强行动画化。
用同一状态函数驱动图、读数和步骤/阶段，提供与该演示相符的暂停、拖动、复位和关键事件。核对边界、退化、零速和终点；符号归一化写明尺度，不增加数值题设。图内短标注、长说明在图外，窄屏可读。未实际运行的计算、交互、视觉和平台预览分别标未测。
```

检查错误解法并做订正演示时，原解法/claims与失败记录保留；订正版另行标注，不把新答案写成用户原来提供的claim。

## 当前会话不能执行时

手机端可用[复制粘贴预览流程](mobile-preview.md)：在聊天网页复制完整HTML或受支持的LessonSpec JSON，打开独立预览器粘贴运行，无需新建文件。它提供运行入口，原题解和布局仍需核对；公开权限不等于已验证学生手机的网络可达性。

电脑端也可保留原HTML与JSON，下载后用普通浏览器导入；独立图解保留推导与完整单文件HTML，下载后打开，不假定它含模板的JSON导入框。源码、截图、文件生成、DOM检查和账号内脚本运行分别说明，不能互相冒充。

具体平台账号尚未完成统一实测；已有用户生成页反馈和本地浏览器验证也不代替逐账号/模式验收。[兼容记录](../docs/browser-compatibility.md)保存各层证据。只复制JSON而没有可运行模板时，也不能宣称已完成网页内核验。

本轮修改与已测范围见[提示词验证记录](../docs/prompt-validation-2026-11-05.md)；单次试答与接口检查不代表跨模型成功率。

## 可选图解评审

默认关闭。想开启时第一次提供web-visual-review完整正文，之后可说“图解评审：开启/关闭”。默认仅本题；明确“本会话开启”才沿用，当前题设置优先，新会话不继承。

该开关增加教学价值和直观性评审，不控制正常的解题正确性、标签不遮挡、单位和基本可读性检查。不开启时不逐题询问或评分。
