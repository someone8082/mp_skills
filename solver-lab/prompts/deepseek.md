# DeepSeek 平台补充提示词

先选一个主入口，可用[通用提示词](web-common.md)、[分步解题提示词](web-study.md)或[复杂题图解提示词](web-advanced.md)。需要时再附题型补充词，从本页复制下方的 `text` 代码块。解题条件以原题为准。

```text
先独立求解。若附有已有解答，完成独立推导后再对照，指出最早造成结论分歧的步骤。求范围时核对端点能否取到、内部极值和中间值能否覆盖。

若要求方向、构型或计数，先给原对象选唯一代表并写明范围。换元后逐根还原为原对象。若涉及无序直线对，逐组列出两条直线的方向或斜率，分别核对交换和镜像所得集合，再按实际构型去重。逐个回代原方程。若有平方步骤，说明等价条件，再回代未平方的原式。同一参数值覆盖多个候选时可合并计算，明确覆盖哪些候选。列出代表值、原对象、回代结果及是否重复。

中间推导、比较和去重使用精确值，最后从精确式统一四舍五入，只用近似值辅助阅读。若具备计算条件，弦交面积题另求候选直线的交点并用鞋带公式核算，列明实际执行的检查。

需要图解时，请优先使用当前 DeepSeek 聊天页面实际提供的 HTML 或代码预览入口。固定模板路线原样预览附件或只替换 lesson-data。模板题只能输出文本时保留 LessonSpec JSON。超出固定模板范围的题，按图解要求交付完整 HTML，按题意提供缩放、拖动、复位与对应步骤。只能显示文本或静态图时保留题解和文件，明确执行状态未确认。

先确认附件是否实际可读，不假装访问仓库相对路径。固定模板若另行修复布局，保留原版、另存并标注衍生版后重新验证；普通JSON换题仍保持模板。新题重新提取条件，只有明确“其余不变”的变式才继承其余已知量。

根据图解实际具备的交互检查运行。固定模板测试播放、时间轴和导入。独立图解测试打开大图、缩放、拖动和复位，有时间或参数演示时再测暂停、拖动、事件跳转及图与读数同步。以消费端聊天网页的实际执行结果为准。

独立图解优先采用保守排版：长说明、公式和数值放在SVG外的可换行HTML中；图内仅留短点名与量符号，详细读数固定展示。按本题实际需要的图独立成框，窄屏单列；不要塞进一个固定宽度、统一缩放且裁切的容器。检查本题的构造步骤、参数边界或运动关键事件的标注位置，避免在箭头末端机械使用同一偏移。拥挤先分图/移说明/用图例，不靠缩小所有字体解决。不能实际运行浏览器时如实说明未视觉核验，仍提供完整可替换HTML。
```

DeepSeek 消费端聊天的完整 JavaScript 预览目前未验证；“未验证”不等于“不支持”。详见 [兼容性记录](../docs/browser-compatibility.md)。

已经生成的页面发生图文堆叠时，可在原会话续接[布局修复提示词](web-layout-repair.md)，附问题截图，无需重发所有解题材料。
