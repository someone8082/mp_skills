# DeepSeek 平台补充提示词

与[通用提示词](web-common.md)或[复杂题图解提示词](web-advanced.md)、题目一起发送；有适用模板时再附HTML：

```text
请优先使用当前DeepSeek聊天页面实际提供的HTML/代码运行或预览入口。固定模板路线原样预览附件或只替换lesson-data；只能输出文本时保留LessonSpec JSON。复杂题按已提供的图解要求独立推导并交付SVG图解HTML，提供缩放、拖动、复位与对应步骤，不把超范围题硬套LessonSpec。只能显示文本或静态图时保留题解和文件，明确执行状态未确认。

根据本文件实际具备的交互检查运行：固定模板测试播放、时间轴和导入；独立图解测试打开大图、缩放、拖动和复位，有时间或参数演示再测暂停、拖动、事件跳转及图与读数同步。只有代码块、静态图或“运行”字样不算完成；不以开发者工具、API或Harness的能力保证消费端聊天网页能力。
```

DeepSeek 消费端聊天的完整 JavaScript 预览目前未验证；“未验证”不等于“不支持”。详见 [兼容性记录](../docs/browser-compatibility.md)。
