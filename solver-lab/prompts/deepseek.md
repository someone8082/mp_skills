# DeepSeek 平台补充提示词

先提供一个主入口：[通用提示词](web-common.md)或[复杂题图解提示词](web-advanced.md)，可再附一份题型补充词；下方只复制text代码块。平台补充只适配展示能力，不改题型和数学物理规则。

```text
请优先使用当前DeepSeek聊天页面实际提供的HTML/代码运行或预览入口。固定模板路线原样预览附件或只替换lesson-data；只能输出文本时保留LessonSpec JSON。复杂题按已提供的图解要求独立推导并交付SVG图解HTML，提供缩放、拖动、复位与对应步骤，不把超范围题硬套LessonSpec。只能显示文本或静态图时保留题解和文件，明确执行状态未确认。

先确认附件是否实际可读，不假装访问仓库相对路径。固定模板若另行修复布局，保留原版、另存并标注衍生版后重新验证；普通JSON换题仍保持模板。新题重新提取条件，只有明确“其余不变”的变式才继承其余已知量。

根据本文件实际具备的交互检查运行：固定模板测试播放、时间轴和导入；独立图解测试打开大图、缩放、拖动和复位，有时间或参数演示再测暂停、拖动、事件跳转及图与读数同步。只有代码块、静态图或“运行”字样不算完成；不以开发者工具、API或Harness的能力保证消费端聊天网页能力。

独立图解优先采用保守排版：长说明、公式和数值放在SVG外的可换行HTML中；图内仅留短点名与量符号，详细读数固定展示。按本题实际需要的图独立成框，窄屏单列；不要塞进一个固定宽度、统一缩放且裁切的容器。检查本题的构造步骤、参数边界或运动关键事件的标注位置，避免在箭头末端机械使用同一偏移。拥挤先分图/移说明/用图例，不靠缩小所有字体解决。不能实际运行浏览器时如实说明未视觉核验，仍提供完整可替换HTML。
```

DeepSeek 消费端聊天的完整 JavaScript 预览目前未验证；“未验证”不等于“不支持”。详见 [兼容性记录](../docs/browser-compatibility.md)。

已经生成的页面发生图文堆叠时，可在原会话续接[布局修复提示词](web-layout-repair.md)，附问题截图，无需重发所有解题材料。
