# ChatGPT 平台补充提示词

先提供一个主入口：[通用提示词](web-common.md)或[复杂题图解提示词](web-advanced.md)，可再附一份题型补充词；下方只复制text代码块。平台补充只适配展示能力，不改题型和数学物理规则。

```text
若附有教材方法卡，先逐卡核对适用性，将相关前提标为「题设已知」「已推导」「尚缺条件」或「与题设不符」，给出题干依据或简短推导。尚缺关键条件时说明缺口或分情况作答，条件不符时改换方法。使用方法的步骤旁注明卡片编号、适用条件及本题式子。把相关常见误用转成本题检查，至少展示一项「检查什么、怎样检查、实际结果」。可用回代、边界比较、另一种计算或还原原对象核对。变式仅作复核建议，原题已知单独保留。卡片未覆盖的步骤独立论证，多卡条件冲突时以原题和可核实的数学关系为准。只引用实际使用的卡片及所附出处。没有提供卡片正文时按题设推导，引用限于实际可读的材料。最终在文字题解或图解题解区保留条件依据和验算结果，实际未执行的程序或交互检查注明未测。

请按已提供的提示词与题目选择路线，并优先使用当前会话实际可用的HTML/代码预览或可执行画布。固定模板路线只替换lesson-data JSON；能直接预览附件时原样打开，我来导入JSON。复杂题路线按已提供的图解要求生成独立SVG图解，提供缩放、拖动和恢复视图，不伪造固定模板JSON或验证通过记录。图解步骤与推导对应，时间轴仅在运动模型需要时提供。

先确认附件是否实际可读，不假装访问仓库相对路径。长说明与读数按主入口的防重叠规则放图外；若另行修复固定模板布局，保留原版，另存并标注衍生版后重新验证，不与普通JSON导入混为一谈。普通新题重新提取条件，不沿用上一题的claims和数值。

若本次有时间或参数演示，再实际操作暂停、拖动、复位与关键事件，检查图和读数同步；只有静态图时不称动画已播放。如果当前网页仅显示源码或下载文件，请写“当前会话尚未确认HTML执行预览”。固定模板保留JSON，复杂题保留推导与完整图解文件；不把代码、静态图或文件生成等同于运行，不假定其他客户端的能力适用于当前会话。
```

账号预览能力尚未实测。官方文件文档对 HTML 交互预览使用条件性描述，不能据此保证每个网页账号可用，见 [兼容性依据](../docs/browser-compatibility.md)。
