# ChatGPT 平台补充提示词

与[通用提示词](web-common.md)或[复杂题图解提示词](web-advanced.md)、题目一起发送；有适用模板时再附HTML：

```text
请按已提供的提示词与题目选择路线，并优先使用当前会话实际可用的HTML/代码预览或可执行画布。固定模板路线只替换lesson-data JSON；能直接预览附件时原样打开，我来导入JSON。复杂题路线按已提供的图解要求生成独立SVG图解，提供缩放、拖动和恢复视图，不伪造固定模板JSON或验证通过记录。图解步骤与推导对应，时间轴仅在运动模型需要时提供。

若本次有时间或参数演示，再实际操作暂停、拖动、复位与关键事件，检查图和读数同步；只有静态图时不称动画已播放。如果当前网页仅显示源码或下载文件，请写“当前会话尚未确认HTML执行预览”。固定模板保留JSON，复杂题保留推导与完整图解文件；不把代码、静态图或文件生成等同于运行，不假定其他客户端的能力适用于当前会话。
```

账号预览能力尚未实测。官方文件文档对 HTML 交互预览使用条件性描述，不能据此保证每个网页账号可用，见 [兼容性依据](../docs/browser-compatibility.md)。
