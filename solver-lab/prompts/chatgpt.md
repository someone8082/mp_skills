# ChatGPT 平台补充提示词

与 [通用提示词](web-common.md)、对应 HTML 附件、题目一起发送：

```text
请优先使用当前会话可用的 HTML/代码预览或可执行画布，在 ChatGPT 页面内打开附带模板。若能编辑文件，只替换 lesson-data JSON 并交付完整 HTML；若能直接预览附件，则原样预览，我来粘贴你输出的 JSON。请保留预览内导入框、播放、暂停、步进与时间轴。

如果当前网页仅显示源码或下载文件、没有可执行 HTML 预览，请明确写“当前会话尚未确认 HTML 执行预览”，继续给 JSON。不要假定网页版具备桌面端的文件预览能力，也不要把生成文件等同于已经运行。
```

账号预览能力尚未实测。官方文件文档对 HTML 交互预览使用条件性描述，不能据此保证每个网页账号可用，见 [兼容性依据](../docs/browser-compatibility.md)。
