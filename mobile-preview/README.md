# 数理图解 · 手机预览器

学生在手机上复制完整HTML或LessonSpec JSON，粘贴后点击运行；无需本机创建文件或提供模型API密钥。代码在当前浏览器运行，预览器没有上传课件或调用模型的接口。

公开入口：[数理图解](https://solver-lab-mobile-20261106-8082.wwk58317.chatgpt.site)。

手机端运行按钮停靠底部；代码输入16px字号，允许用户正常缩放。预览随可视高度变化，运行时取消输入焦点；返回编辑和报错时不会自动聚焦代码框。横屏缩短工具栏，刘海屏两侧和底部预留安全区。预览器不强制修改粘贴课件的布局，原HTML仍应自行支持窄屏和窗口大小变化。

## 使用

1. 用系统浏览器打开网站，粘贴完整代码。外层的一组html/json代码围栏可保留，其他解题说明不要复制。
2. 点击“运行图解”；预览占满页面，顶部可返回编辑或停止，底部可重新运行。
3. 图解的按钮、动画和滚动由原HTML负责。预览器解决入口和运行，不替原页面修正数学或排版。
4. 也可选择运动、电路、截面示例；JSON在母页调用原内核检查，再嵌入原模板。不通过时清空旧框架并保留错误。

支持HTML内联脚本、CSS、SVG与data/blob图片；不支持依赖远程脚本、CDN、外部字体或联网接口的课件。JSON支持范围与原solver-lab一致，不能把一般电路硬套串联。最近三条记录与草稿在当前浏览器保存，清除浏览器数据后不再保留。

## 本地开发

```sh
node scripts/build.mjs
node scripts/serve.mjs 8767
```

打开终端输出的本机地址。开发运行需要Node.js 22+，部署后的学生端只需浏览器。静态服务器必须为`.mjs`提供JavaScript MIME，不能用Windows上默认把它当text/plain的配置。

测试需要开发依赖：`npm install`后运行`npm test`。运行站点本身不需要npm依赖。构建脚本优先从父项目skills/solver-lab更新运行快照；独立检出时使用vendor/内的同一批模块和模板。

## 安全边界

HTML在仅开放allow-scripts的iframe内执行，不开放allow-same-origin。父页不能把任意输入当自身HTML插入；历史标题用textContent显示。父/子CSP限制联网、外部脚本、表单、框架及导航。每次停止、回编辑或新运行都会替换旧iframe，避免旧执行上下文复用；异步模板只接受最近一次请求。

这不是抵抗恶意代码的进程级容器，不能保证中断死循环或防止资源耗尽。只运行可辨认、可信来源的图解。生成代码的题意、数学正确性、可读性须另外核对。添加主屏幕和离线缓存不在第一版范围。
