# 数理图解 · 手机预览器

学生在手机上复制完整HTML或LessonSpec JSON，粘贴后点击运行；无需本机创建文件或提供模型API密钥。代码在当前浏览器运行，预览器没有上传课件或调用模型的接口。

公开站点可免登录使用。普通访客生成提示词和运行图解共用 20 次每日额度，按北京时间零点刷新。匿名访客由本站的签名 Cookie 区分，兑换邀请码后当前浏览器不限次数。输入管理员验证码可开启不限次数的管理会话，并在「管理邀请码」换码。旧码停止接受新兑换，已兑换记录继续有效。

公开入口：[数理图解](https://solver-lab-mobile-20261106-8082.wwk58317.chatgpt.site)。

手机端运行按钮停靠底部；代码输入16px字号，允许用户正常缩放。预览随可视高度变化，运行时取消输入焦点；返回编辑和报错时不会自动聚焦代码框。横屏缩短工具栏，刘海屏两侧和底部预留安全区。预览器不强制修改粘贴课件的布局，原HTML仍应自行支持窄屏和窗口大小变化。

## 使用

1. 用系统浏览器打开网站。可以先打开「生成提示词」，选择题型和 AI，填题后复制提示词到 AI 对话。也可以选匀变速、竖直上抛或正方体截面试用题。

   [教材方法入口](https://solver-lab-mobile-20261106-8082.wwk58317.chatgpt.site/?mode=study)默认生成文字题解。本项目的构建数据包括《高考必刷题·数学合订本》12 章、原数学讲义 58 讲、力学 15 专题和物理配套课件 18 份。自动推荐至多两张，也可按册和章手选。提示词包含适用前提、步骤、易错点、变式与出处。需要动画时选择「解题与交互图解」。
2. 回到「运行代码」，粘贴完整 HTML、模板 JSON，或只含一个 HTML/JSON 代码块的整段回复。回复含多个代码块时，只复制需要运行的那一个。
3. 点击「运行图解」。顶部可返回编辑或停止，底部可重新运行；图解故障可通过「图解有问题」生成修复提示，粘回原对话。
4. JSON 由原内核校验，再嵌入原模板。独立 HTML 的脚本与资源拦截报告可辅助排查。图内的数学推导、控件和排版仍由课件负责。

支持 HTML 内联脚本、CSS、SVG 与 data/blob 图片。课件须自带资源。JSON 入口接收 `version: 1` 的 `motion`、`circuit`、`section` LessonSpec。旧版 ProblemSpec 用 solver-lab CLI 运行，超出网页模板范围的课件可使用完整 HTML。最近三条记录与草稿保存在当前浏览器，清除浏览器数据后不再保留。

## 本地开发

```sh
node scripts/build-site.mjs
node scripts/serve.mjs 8767
```

打开终端输出的本机地址。开发运行需要 Node.js 22+。本地服务器仅监听回环地址，以内存数据库预览匿名访客流程。测试兑换码为 `local-invite`，测试管理员验证码为 `local-admin`。重启服务后本地数据库状态清空。

测试需要开发依赖：`npm install`后运行`npm test`。运行站点本身不需要npm依赖。`npm run build` 同样构建完整 Worker。构建脚本依次查找父项目的 `skills/solver-lab`、本仓库的 `solver-lab`，缺少时使用 `vendor/` 内的模块和模板快照。

切换题型会同步更新试用题和参考专题；输入题目后按实际匹配显示至多两张卡，推荐不合适时可手选。方法卡随页面内嵌，手选目录不依赖另外下载 JSON。参考卡和实际匹配的卡会明确区分，只有实际匹配或手选的卡加入提示词。独立重建与验收要求见 [网站搭建约束](BUILD_CONSTRAINTS.md)。

## 安全边界

HTML在仅开放allow-scripts的iframe内执行，不开放allow-same-origin。父页不能把任意输入当自身HTML插入；历史标题用textContent显示。父/子CSP限制联网、外部脚本、表单、框架及导航。每次停止、回编辑或新运行都会替换旧iframe，避免旧执行上下文复用；异步模板只接受最近一次请求。

这不是抵抗恶意代码的进程级容器，不能保证中断死循环或防止资源耗尽。只运行可辨认、可信来源的图解。生成代码的题意、数学正确性、可读性须另外核对。添加主屏幕和离线缓存不在第一版范围。

## 发布

运行 `node scripts/build-site.mjs` 构建 Worker。Sites 运行环境提供三个机密变量 `QUOTA_SIGNING_KEY`、`QUOTA_INITIAL_INVITE`、`QUOTA_ADMIN_ACTIVATION` 和 D1 的 `DB` 绑定。日计数、兑换状态和管理员绑定保存在 D1。题目数据和课件代码不进入计次 API。

使用`.openai/hosting.json`的现有project_id，通过Sites源码工作流打包dist并保存部署。发布源仓库仅含本项目；不包含父项目的资料、凭证或其他未提交改动。新站默认私有，匿名学生入口需要明确公开访问授权；不要把“创建站点”当作已上线。
